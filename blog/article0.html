如何使用 GitHub Pages 搭建个人博客

发布于 2026-05-02 • 阅读时间：114514 分钟

GitHub Pages 是 GitHub 提供的一项免费静态网站托管服务，非常适合用来搭建个人博客、项目文档或作品集网站。本文将详细介绍如何从零开始，使用 GitHub Pages 搭建一个完全免费的个人博客。

第一步：创建 GitHub 仓库

首先，你需要一个 GitHub 账号。如果你还没有，可以去 GitHub 官网 免费注册一个。

  1. 登录 GitHub 后，点击右上角的 "+" 号，选择 "New repository"
  2. 仓库名称必须为 你的用户名.github.io
  3. 选择 "Public"（公开仓库）
  4. 勾选 "Add a README file"
  5. 点击 "Create repository"

第二步：创建第一个页面

仓库创建完成后，我们来创建第一个 HTML 页面。

  1. 点击仓库页面上的 "Add file" 按钮，选择 "Create new file"
  2. 文件名输入 index.html
  3. 在内容区域输入以下代码：
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的第一个 GitHub Pages 网站</title>
</head>
<body>
    <h1>Hello, GitHub Pages!</h1>
</body>
</html>

然后点击页面底部的 "Commit new file" 按钮提交代码。

第三步：启用 GitHub Pages

现在我们需要启用 GitHub Pages 服务：

  1. 点击仓库页面上的 "Settings" 标签
  2. 在左侧导航栏中找到 "Pages" 选项
  3. 在 "Build and deployment" 部分，将 "Source" 设置为 "Deploy from a branch"
  4. 将 "Branch" 设置为 "main" 分支，文件夹选择 "/ (root)"
  5. 点击 "Save" 按钮

等待几分钟，GitHub 就会自动部署你的网站。部署完成后，你就可以通过 https://你的用户名.github.io 访问你的网站了。

第四步：配置自定义域名

如果你有自己的域名，可以将它配置到 GitHub Pages 上：

  1. 在域名注册商那里，将域名的 DNS 解析指向 GitHub Pages 的服务器
  2. 在 GitHub 仓库的 "Settings" → "Pages" 页面，找到 "Custom domain" 部分
  3. 输入你的自定义域名，点击 "Save"
  4. 勾选 "Enforce HTTPS" 选项，开启 HTTPS

总结

恭喜你！你已经成功搭建了一个基于 GitHub Pages 的个人博客。接下来，你可以继续完善你的网站，添加更多的文章和功能。

GitHub Pages 不仅免费，而且非常稳定，是搭建个人博客的绝佳选择。希望这篇文章对你有所帮助！
